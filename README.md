# The Pink Haired Potter — Website

Shop with a cart, gallery, custom-order requests, and a private admin page for **The Pink Haired Potter** (Allison Almloff, Olathe, KS).

Runs on **Cloudflare Pages** (static site + Functions, D1 database, R2 photo storage, Access login) with **Stripe Checkout** for payments.

- **First-time setup:** see [SETUP-GUIDE.md](SETUP-GUIDE.md)
- **Day-to-day use:** see [ADMIN-GUIDE.md](ADMIN-GUIDE.md)

Cloudflare Pages build settings: framework **None**, build command **blank**, output directory **`public`**.
